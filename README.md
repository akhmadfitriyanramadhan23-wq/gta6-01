Solmar Bay — an original 2D top-down open-world crime game in the spirit of GTA 6. Explore a 3200×2400 sun-soaked city on foot and by car, steal cars, outrun the police across a 0–5 star wanted level, run three story missions with Rook and Mara, take taxi fares, and hunt 10 hidden cash stashes. Vanilla JavaScript and canvas, no libraries, no network — just open `game/index.html` in desktop Chrome and play.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
